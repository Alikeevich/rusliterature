# Адал азамат — беседы с героями книг

Сайт для уроков русской литературы и русского языка (6–9 классы). Это стена с вкладками по классам. В каждой вкладке есть персонажи и авторы произведений из программы. Ученик нажимает на карточку и задаёт персонажу вопрос в чате. Отвечает ИИ Google Gemini в роли этого персонажа.

## Структура

| Файл | Что в нём |
|---|---|
| `index.html`, `style.css`, `app.js` | Страница: вкладки, карточки, окно чата (без сборки и фреймворков) |
| `data/characters.js` | Список персонажей по классам: имя, произведение, приветствие, подсказки-вопросы и **промпт персонажа** (`persona`) |
| `api/chat.js` | Серверная функция Vercel: берёт промпт персонажа, добавляет общие правила роли и обращается к Gemini |

Ключ Gemini хранится только на сервере и в браузер не попадает. Сервер принимает только id персонажа, поэтому ученик не может подменить промпт.

## Как выложить на Vercel

1. Получите ключ Gemini: https://aistudio.google.com/apikey
2. На https://vercel.com нажмите **Add New → Project** и импортируйте этот репозиторий. Framework Preset оставьте **Other**, настройки сборки не нужны.
3. В **Settings → Environment Variables** добавьте:
   - `GEMINI_API_KEY` — ваш ключ (обязательно);
   - `GEMINI_MODEL` — модель (необязательно, по умолчанию `gemini-2.5-flash`).
4. Нажмите **Deploy**. Если ключ добавили после первого деплоя, сделайте **Redeploy**.

## Локальный запуск

```bash
npm i -g vercel
vercel dev
```

Ключ для локального запуска положите в файл `.env.local` (`GEMINI_API_KEY=...`). Этот файл не коммитится.

## Как добавить или изменить персонажа

Добавьте объект в массив `CHARACTERS` в `data/characters.js`:

```js
{
  id: "unique_id",          // латиницей, без пробелов
  grade: 7,                 // класс
  name: "Имя персонажа",
  role: "кто он",
  work: "«Название»",
  author: "Автор",
  emoji: "📘",
  color: "#2f80ed",
  greeting: "Первая реплика в чате",
  suggestions: ["Вопрос 1", "Вопрос 2", "Вопрос 3"],
  persona: `Кто ты, твоя история, характер, манера речи...`,
}
```

Общие правила для всех персонажей лежат в функции `buildSystemPrompt` в `api/chat.js`: тема «Адал азамат», ответы на русском, не выдумывать фактов, не писать за ученика домашние задания и т. д.
