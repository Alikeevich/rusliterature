# Адал азамат - беседы с героями книг

Сайт для уроков русской литературы и русского языка (6-9 классы). Стена героев книг с вкладками по классам. Ученик нажимает на карточку и задаёт герою вопрос в чате на весь экран. Отвечает языковая модель в роли этого героя.

Стек: Next.js 15 (App Router), React 19, TypeScript, Tailwind CSS 4, Motion (анимации), lucide-react (иконки).

## Структура

| Путь | Что там |
|---|---|
| `app/page.tsx`, `components/Wall.tsx` | Шапка, переключатель классов, сетка карточек |
| `components/Chat.tsx` | Чат на весь экран |
| `components/Portrait.tsx` | Фото героя (или инициалы, если фото нет) |
| `app/api/chat/route.ts` | Серверная часть: берёт промпт героя и обращается к модели |
| `lib/characters.ts` | Герои по классам: имя, произведение, приветствие, подсказки-вопросы и промпт (`persona`) |
| `lib/prompt.ts` | Общие правила для всех героев |
| `public/img/people/`, `lib/photos.ts` | Обрезанные фотографии |
| `tools/photos.py` | Скрипт, который обрезает фото по лицу |

Ключ API хранится только на сервере. Сервер принимает только id героя, поэтому ученик не может подменить промпт.

## Как выложить на Vercel

1. Получите ключ: https://aistudio.google.com/apikey
2. На https://vercel.com нажмите **Add New, Project** и импортируйте этот репозиторий. Vercel сам определит Next.js, ничего настраивать не надо.
3. В **Settings, Environment Variables** добавьте:
   - `GEMINI_API_KEY` - ваш ключ (обязательно);
   - `GEMINI_MODEL` - модель (необязательно, по умолчанию `gemini-3.8-flash`; если модель недоступна, сервер сам пробует запасные).
4. Нажмите **Deploy**. Если ключ добавили после первого деплоя, сделайте **Redeploy**.

## Локальный запуск

```bash
npm install
```

```bash
npm run dev
```

Ключ для локального запуска положите в файл `.env.local` (`GEMINI_API_KEY=...`). Этот файл не коммитится.

## Фотографии

1. Положите исходники в папку `photos/` и назовите каждый файл по полю `person` героя, например `photos/abai.jpg`.
2. Запустите `python3 tools/photos.py` (нужны `pillow` и `opencv-python-headless<5`).
3. Скрипт найдёт лицо и сделает портрет 4:5 и квадратную аватарку в `public/img/people/`, а список фото запишет в `lib/photos.ts`.
